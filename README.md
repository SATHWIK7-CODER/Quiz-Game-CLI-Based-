# 🎮 Terminal Tech Quiz

A lightweight, interactive command-line quiz application built with Python.

## 📋 Overview
This project is a simple yet extensible quiz engine. It is designed to challenge users with technical questions while providing a clean, randomized experience every time it is played.

## ✨ Key Features
*   **Randomized Gameplay**: The script uses `random.shuffle()` so questions appear in a different order every session[cite: 6, 7].
*   **Score Tracking**: Real-time tallying of correct answers[cite: 7, 8].
*   **Input Validation**: Uses `try-except` blocks to ensure the game doesn't crash if you type a letter instead of a number[cite: 6, 7].
*   **Final Grade**: Provides a percentage-based score and a final result summary.

## 🚀 How to Use
1.  **Save the code**: Copy the Python script into a file named `quiz_game.py`[cite: 7].
2.  **Open Terminal**: Navigate to the folder where you saved the file.
3.  **Run**: Execute the command: 
    ```bash
    python quiz_game.py
